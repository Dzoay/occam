# The OCCT oracle stands

**Decided by the user, 2026-11-09:** "OCCT oracle is allowed."

## What it means in practice

This confirms the reading in [no copyleft](2026-11-08-no-copyleft.md): a pinned OCCT binary may run outside the
workspace as a black-box oracle, because a program that is never committed is not in the repository. What may be done
with it is set out in [the licence and provenance decision](2026-11-08-licence-and-provenance.md), and nothing else about
that decision changes. Whether oracle outputs carry licence terms remains open as O6 in
[the plan](../PLAN.md#7-decisions-the-user-still-owns).
