# serde and serde_json

**Decided by the user, 2026-11-09:** "serde and serde_json are generally ok".

## What it means in practice

This section is Claude's working reading of the decision. The user can change it.

- Any crate in the workspace may use `serde` and `serde_json` to read or write JSON without asking again, so nobody writes a
  JSON layer by hand. `occam-verify`, which reads the oracle's result files, is the first to use this.
- `ci/dependencies.txt` still has a line for each crate using them, and `gates deps` still holds that list.
- Every other dependency still needs its own yes.
