# The name

**Decided by the user, 2026-11-08: the project is called `occam`.**

Chosen over `ogee`, `isogon` and `planish`. The name carries Occam's razor (the brief's "clean, simple"), contains OCC,
the usual short form of Open CASCADE, and is also the name of a 1980s parallel programming language.

Checked on 2026-11-08, exact names only:

- crates.io: `occam` is free.
- npm: `occam` is taken, so the browser package needs a scope or a suffix. `occamkit` is free on both registries.
- GitHub: small unrelated repositories use the name; the largest found has 50 stars.
- Trademarks were not checked.

Nothing has been reserved on any registry.
