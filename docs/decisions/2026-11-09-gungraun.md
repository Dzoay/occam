# gungraun for the instruction-count gate

**Decided by the user, 2026-11-09:** "yes to wasm-bindgen and gungraun". `occam` may have `gungraun` as a dev-dependency.

## What it means in practice

This section is Claude's working reading of the decision. The user can change it.

- It is for benchmarks only, so it never reaches a build of the kernel. The crate is pinned exactly, to the version of
  `gungraun-runner` in `scripts/toolchain.sh`, because the two must match.
- Its transitive crates are listed in `ci/dependencies.txt` against this decision. All are MIT or Apache-2.0, so
  [the no-copyleft decision](2026-11-08-no-copyleft.md) holds.
